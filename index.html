Voice needs a secure (HTTPS) page

  1. Open app.netlify.com/drop.
  2. Rename this file to index.html and drag it onto the page.
  3. Open the provided https://…netlify.app link in Chrome.
  4. Allow microphone access. Microphone input and Live Voice will then be available.
  5. Optionally, use Chrome menu → Add to Home screen.
Text chat, file reading, and Read Aloud are available now. Browser microphone access requires a secure HTTPS page. This is a browser security requirement.
